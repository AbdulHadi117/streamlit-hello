# Streamlit Hello World

A minimal deployment smoke test for running a **Python Streamlit** application on **Streamlit**. 

## 🛠️ Stack
* **Language:** Python
* **Framework:** Streamlit
* **Deployment Platform:** Streamlit

---

## 🚀 Local Development

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AbdulHadi117/streamlit-hello.git
   cd streamlit-hello
   ```

2. **Set up a virtual environment (optional but recommended):**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows use `venv\Scripts\activate`
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the Flask app:**
   ```bash
   streamlit run app.py
   ```
   Open the designated localhost url in your browser to view the application.
